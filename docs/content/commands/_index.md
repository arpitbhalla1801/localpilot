## localpilot

Your command center for everything running on your machine

### Synopsis

LocalPilot helps you discover, understand, diagnose, and control everything running on localhost.

```
localpilot [flags]
```

### Examples

```
  localpilot                # dashboard of everything listening on localhost
  localpilot port 3000       # what's using port 3000?
  localpilot kill 3000       # free it up (with confirmation)
```

### Options
